# Startup Lab Hackathon — Track 2: RFQ to Quote (Rudco)

Get Hired Hack @ Columbia Startup Lab, Oct 10 2026.

An agent that turns a messy industrial RFQ (email, PDF, spreadsheet) into a ready-to-send quote:
standard specs, catalog matches, benchmarked prices, compliance flags, and clarifying questions
for anything ambiguous instead of guesses.
